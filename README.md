# Sign-language-recognition-system
A real-time sign language recognition system using OpenCV, MediaPipe, and LSTM deep learning to detect hand gestures and convert them into letters and common words
Project Title: Sign Language Recognition
Domain: Machine Learning / Deep Learning
Objective: To recognize hand gestures and convert them into letters and common words.
Input: Live webcam video.
Hand Detection: MediaPipe Hands.
Image Processing: OpenCV.
Feature Extraction: Hand landmark coordinates.
Model: LSTM neural network.
Framework: TensorFlow / Keras.
Supported Signs: A–Y, HELLO, YES, NO, LOVE, BYE.
Output: The recognized sign is displayed on the screen.
Real-Time Recognition: The system identifies signs directly from the webcam feed.
Applications: Communication assistance, accessibility, and learning.
